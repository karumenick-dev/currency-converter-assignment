**Your Personal Expense Tracker**

If you're someone who's a travel enthusiast, this one's for you! What this web application does is track your spending on each expense, allowing you to log your spending in multiple currencies.

**Live demo link (GitHub Pages)**


**Features list**
Multiple Currencies to choose from.
View all your logged expenses in their original currency and your converted home currency.
Filter your expenses by their respective categories.

**How to run it locally**
1. Open the terminal and clone the repository:

git clone https://karumenick-dev.github.io/currency-converter-assignment/

2. Navigate into the project directory:

cd Currency Converter Assignment

3. Open the project in VS Code:

code .

4. Open the index.html file in your preferred web browser to view the application live.
